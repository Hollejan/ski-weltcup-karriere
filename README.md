# ⛷️ Ski-Weltcup-Karriere

Karrierespiel im alpinen Ski-Weltcup (Saison 2026/27 und folgende) – als installierbare Web-App (PWA).

**Spielen:** https://hollejan.github.io/ski-weltcup-karriere/

- iPhone: in Safari öffnen → Teilen → „Zum Home-Bildschirm“
- Android: in Chrome öffnen → Menü ⋮ → „App installieren“

Läuft offline, Spielstand wird lokal auf dem Gerät gespeichert.
